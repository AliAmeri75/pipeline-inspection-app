This web application supports reliability- and risk-informed selection of fixed
pipeline intervention intervals. It compares two strategies for systems
containing multiple pipe joints: prior excavation scheduling without inline
inspection (ILI), and pre-posterior scheduling informed by uncertain ILI
detection and sizing. Monte Carlo simulation represents uncertain crack
initiation, crack growth, repair, leakage, and burst events.

The current version is intended as a transparent research and demonstration
tool. Users can define joint groups and initial cracks, adjust deterioration and
economic assumptions, optimize each method over the same candidate intervals,
and calculate the net value of ILI information as the optimized prior cost minus
the optimized ILI-informed cost.
