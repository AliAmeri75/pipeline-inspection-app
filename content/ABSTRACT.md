This web application supports reliability- and risk-informed selection of fixed
inspection intervals for pipeline systems containing multiple pipe joints. It
uses Monte Carlo simulation to represent uncertain crack initiation, crack
growth, measurement error, detection, repair, leakage, and burst events. The
candidate schedules are compared using safety criteria and expected life-cycle
costs, allowing users to examine the trade-off among inspection frequency,
repair demand, and failure consequences.

The current version is intended as a transparent research and demonstration
tool. Users can define joint groups and initial cracks, adjust deterioration and
economic assumptions, compare candidate equidistant intervals, and download the
resulting schedule table for further review.
